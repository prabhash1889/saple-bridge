Product cut

Focused, local, inspectable.

Lazarus keeps Traycer’s strongest architectural lesson—the separate machine authority— while choosing a calmer project-and-timeline experience and a much smaller first release.

Different UI

Project workbench

Project rail, objective/run navigator, one focused surface, and one optional evidence inspector.

Two surfaces

Chat + Terminal

Structured event-driven conversations and real provider-native PTYs without forcing one abstraction.

Local-first

No account required

Projects, sessions, artifacts, and change inspection work offline with existing provider logins.

Open format

Plain Markdown artifacts

Specs, decisions, checklists, and reviews remain normal project files that any editor can read.

Safe execution

Explicit worktrees

Each run exposes its exact execution location; isolated work is chosen, never hidden.

Evidence

Activity timeline

Turns, tools, approvals, checkpoints, and changes form a reconstructable history for each objective.

Runtime topology

Authority has a home.

Electron stays narrow. The renderer stays browser-safe. The daemon owns every operation that can affect source code, processes, terminals, Git, or durable operational state.

Load-bearing decisions

Constraints before code.

Storage

SQLite + Markdown

Operational events are transactional; user-authored artifacts remain open project files.

Transport

Authenticated localhost WebSocket

One validated channel supports unary requests, replayable streams, and binary terminal frames.

Compatibility

One protocol version in v1

Per-method negotiation waits until client and daemon actually ship independently.

Providers

Behavioral adapters

Codex and Claude share lifecycle contracts while retaining provider-specific session records and capabilities.

Mutation safety

Reconcile, never guess

Possibly-applied commands are checked by request ID before any retry.

Scope

Cloud is deferred

No accounts, sync interfaces, CRDTs, relay, or remote-daemon registry are pre-built in v1.

Non-negotiable:

Schedule pressure may remove convenience features, but never renderer isolation, durable acknowledgement, approval enforcement, path containment, restart recovery, or destructive-operation guards.
